# create-wdk-module

CLI de scaffolding (`@tetherto/create-wdk-module`) que genera un proyecto con fuentes, tests, tipos TypeScript y CI para un módulo nuevo de siete tipos: wallet, swap, bridge, lending, fiat, swidge y sda. El nombre del paquete generado sigue las convenciones de WDK, y el proyecto es un punto de partida con la lógica de integración por escribir. Se ejecuta con `npx`, de forma interactiva o con argumentos.
