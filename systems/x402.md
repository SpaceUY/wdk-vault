# x402

Guía de integración de pagos HTTP con el protocolo x402 y USD₮0: el comprador firma una autorización EIP-3009, y el servidor la verifica y la liquida a través de un facilitator. Con el módulo EVM, `WalletAccountEvm` satisface el signer de cliente de x402 de forma directa. Del lado vendedor se depende de un facilitator externo que Tether no opera, y para uno autoalojado la doc no da un conjunto de versiones verificado.

## Structural
- depends on → [[wdk-wallet-evm]] because los ejemplos de cliente firman con `WalletAccountEvm`, que satisface el signer de x402 sin adaptador

## Associative
- opens a question about → [[wdk-wallet-evm-x402-facilitator]] because la doc lo describe como adaptador para un facilitator autoalojado, pero advierte que su signer no coincide del todo con el contrato de x402 de los ejemplos
