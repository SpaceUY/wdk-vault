# wdk-uikit-react-native

Kit de componentes React Native temables para wallets (entrada de monto, selector de activos, direcciones, QR, listas de transacciones y frase semilla), publicado como `@tetherto/wdk-uikit-react-native`. No incluye lógica de negocio: los datos y el estado se conectan desde el WDK.

## Associative
- contrasts with → [[wdk-react-native-core]] because el kit es presentación sin lógica y la librería core es estado y operaciones de wallet
