# Agent Skills WDK

Conjunto de instrucciones `SKILL.md`, según la especificación AgentSkills, que enseña a un agente a usar el SDK del WDK para wallets, swaps, bridges, lending, fiat e indexer. Toda escritura requiere confirmación humana, y la skill incluye guía contra inyección de prompts y limpieza de claves. Existe además una variante comunitaria para OpenClaw que se instala desde ClawHub, sin respaldo de Tether.

## Associative
- contrasts with → [[wdk-mcp-toolkit]] because la doc recomienda la skill para plataformas que cargan instrucciones desde archivos y el toolkit para construir un servidor MCP en código
